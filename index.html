03

System Architecture & Signal Pipeline

Out-of-band communication topology ensuring strict air-gap compliance and zero host attack surface.

STAGE 01
📱 Mobile Client
Cross-platform Flutter application captures multi-touch gestures, button taps, and scroll deltas with sub-pixel velocity scaling.
STAGE 02
📶 2.4 GHz SoftAP
Low-overhead asynchronous WebSockets transmit binary input frames over dedicated wireless link with < 25ms SLA round-trip latency.
STAGE 03
⚡ ESP32-S3 Bridge
FreeRTOS dual-core engine decodes frames on Core 0 and injects USB HID reports via TinyUSB driver on Core 1 in parallel.
STAGE 04
💻 Target Host PC
Native hardware USB PHY receives standard differential D+/D- signals. Zero host drivers, zero software agents, zero network inbound ports.
