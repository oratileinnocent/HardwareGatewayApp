03 Project Abstract & System Overview

Abstract: This capstone project introduces an air-gap compliant, out-of-band hardware gateway engineered using the dual-core Espressif ESP32-S3 microcontroller. Unlike conventional remote desktop software (TeamViewer, AnyDesk, RDP) which require host operating system daemons and privileged background access, this system operates entirely at the physical bus layer by emulating composite USB Human Interface Device (HID) optical mouse and keyboard hardware via native on-chip USB 2.0 OTG PHY. Remote user input is transmitted from a custom cross-platform Flutter application over low-latency WebSockets (<25 ms RTT) directly into physical differential D+/D- lines. The system guarantees 100% pre-boot UEFI/BIOS accessibility, leaves a 0 MB host software footprint, and provides complete air-gap isolation at one-tenth the cost of enterprise IP-KVM solutions.
