Hardware-Level USB Remote Access Gateway via ESP32-S3

A driverless, air-gap compliant hardware remote bridge emulating USB Composite HID peripherals over full-duplex WebSockets to control computers without host software or network agents.

01

The Problem

Traditional software remote desktop solutions (TeamViewer, AnyDesk, Windows RDP) require host operating system daemons, administrative installation privileges, and open network inbound ports. Consequently, they are strictly prohibited in air-gapped industrial control rooms, financial institutions, and secure forensic labs due to massive cybersecurity attack surfaces. Furthermore, software tools are completely blind during pre-boot UEFI/BIOS configuration, kernel crashes, or OS installation lockouts, leaving engineers with no remote recourse.

02

Our Approach

We designed a driverless, out-of-band hardware gateway using the dual-core Espressif ESP32-S3 microcontroller, leveraging its integrated on-die USB 2.0 Full-Speed On-The-Go (OTG) PHY. The firmware, written in embedded C++ on FreeRTOS, emulates a genuine USB Composite Human Interface Device (HID) optical mouse and 104-key keyboard. Remote inputs from a cross-platform Flutter client application are transmitted over low-latency WebSockets, decoded, and injected directly into target PC hardware via USB differential data lines (D+/D-).

Empirical bench testing over dedicated 2.4 GHz wireless links demonstrated 0% packet drop across 25,000 transmitted HID reports, sub-pixel cursor glide smoothness, and zero host CPU or RAM overhead. The system successfully executed cold-boot remote recovery directly inside the UEFI/BIOS menu and Windows login security screens without triggering any antivirus or EDR endpoint alarms.
